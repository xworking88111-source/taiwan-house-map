# 為什麼寫死版本 (==)？
#   寫 >= 的話，每次安裝都會拿到「最新版」：哪天 pandas 或 XGBoost 改版，同一份程式可能算出不同結果、甚至壞掉。
#   寫死版本 = 任何人、任何時間安裝，都拿到「驗證過」的同一組套件 (可重現性 reproducibility)。
#   要升級時：改版本號 → 跑 pytest 和 train.py → 成績沒變差才 commit。
